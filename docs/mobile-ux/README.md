# Kodik · единый мобильный интерфейс

Интерактивный прототип реализован в настоящем приложении. Один основной курс содержит 100 заданий в 12 главах. Снимки ниже показывают состояния при ширине 390 px. Мобильная страница закреплена по высоте экрана; главы и страницы карты переключаются кнопками. Внутри редактора, справки и результатов можно просматривать длинное содержимое.

## Основа дизайна

| Роль | Значение |
| --- | --- |
| Фон | `#f8f7f2` |
| Поверхность | `#fffefa` |
| Мягкая поверхность | `#edf0e8` |
| Основной текст | `#17352e` |
| Вторичный текст | `#68766f` |
| Основное действие | `#17463a` |
| Тёплый акцент | `#c77c5d` |
| Разделитель | `#e2e5dd` |

Текст интерфейса использует системный шрифт, код — моноширинный. Обычные карточки имеют мягкую границу и радиус около 20 px. В уроке сохраняется один главный шаг: задача → рабочая область → проверка. Вспомогательные действия остаются рядом с соответствующим контентом или открываются снизу. Форма и поведение самих блоков не менялись.

## Сценарий и экраны

1. [Главная](01-home.png): приветствие, прогресс, следующий шаг, курс и нижняя навигация.
2. [Карта курса](02-path.png): прогресс, главы и статусы уроков.
3. [Урок с блоками](03-block-lesson.png): задача, рабочая область и одна основная кнопка.
4. [Выбор блока](04-add-block-sheet.png): мобильный нижний лист.
   [Клавиатура Kodik](04a-number-keyboard.png): ввод числа без системного окна Safari; для текста есть русская и английская раскладки.
5. [Python](05-python-preview.png): компактная карточка и подробный просмотр.
6. [Выбор фрагмента](06-guided-input.png): код с опорой.
7. [Сборка строки](07-token-input.png): ввод из частей.
8. [Свободный ввод](08-free-input.png): спокойный редактор с номерами строк.
9. [Набор текста](09-typing-keyboard.png): фокус, активная строка и кнопка над клавиатурой. Клавиатура на снимке имитирована; приложение использует реальную геометрию `visualViewport` на телефоне.
10. [Ошибка](10-error.png): мягкая обратная связь, объяснение и повторная проверка.
11. [Успех](11-success.png): результат и продолжение урока.
12. [Глава основного курса](12-extended-course.png): новый материал в общей карте курса.
13. [Финальный проект](13-final-project.png): рисунок, выполненный настоящим учебным движком.

Первые 22 шага сохраняют обучение от блоков к Python. Затем идут 78 новых практических задач, разборы тем и примеры. Первые задания на новую конструкцию могут предлагать заполнить готовый каркас. Ввод проверяется на нескольких наборах данных, рисунки — по отрезкам. Эталонные решения всех 100 шагов проверены; автоматический сценарий также проходит все шаги через интерфейс до финала.

Для обновления снимков запустить локальный сервер, затем `node ./node_modules/tsx/dist/cli.mjs scripts/capture-mobile-ux.mjs`.
