# Библиотеки учебного Python: turtle, pyrob.api, math, random, time, numpy, matplotlib.pyplot

Ученик подключает библиотеку обычным импортом, запускает программу в Kodik и видит результат: текст, рисунок черепахи с анимацией, поле Робота или график. Справка с запускаемыми примерами и точными ограничениями — пункт меню «Справка Python» (`#python-help`), ссылка есть и в редакторе ученика, и в конструкторе задания.

## Что поддерживается

| Модуль | Возможности |
|---|---|
| `turtle` | движение и повороты, перо, координаты и направление, цвета (имена, `#rrggbb`, `(r, g, b)`, `colormode`), толщина, `circle` и дуги, `dot`, заливка, `write`, вид исполнителя (`shape`, `shapesize`, `hideturtle`, `stamp`), несколько черепах, `Screen`, `bgcolor`, `setup`, `setworldcoordinates`, `clear`/`reset`/`clearscreen`, анимация по `speed`, кадры `tracer(0)`/`update()` |
| `pyrob.api` | поле со стенами из задания или из программы (`set_field_size`, `goto`, `put_wall`, `set_cell_type`, `set_parking_cell`), `move_*`, `fill_cell`, датчики стен и клеток, `get_pos`, `@task`/`run_tasks`, итог поля (закрашено, лишнее, парковка, столкновение) |
| `math` | `sqrt`, `isqrt`, `pow`, `exp`, `fabs`, `ceil`, `floor`, `trunc`, тригонометрия, `degrees`/`radians`, логарифмы, `factorial`, `gcd`, `isclose`, `hypot`, `pi`, `e`, `tau`, `inf`, `nan` |
| `random` | `randint`, `randrange`, `random`, `uniform`, `choice`, `shuffle`, `seed` — генератор Mersenne Twister и целочисленные алгоритмы CPython 3.11, результаты после `seed` совпадают с Python |
| `time` | `sleep` — пауза в воспроизведении, страница не зависает; `time`, `monotonic`, `perf_counter` |
| `numpy` | массивы int64/float64/bool любой размерности, `array`, `zeros`, `ones`, `full`, `arange`, `linspace`, индексы, срезы, маски, широковещание, поэлементная арифметика и сравнения, ufunc-функции, итоги с `axis`, `reshape`, `T`, `astype`, печать как в NumPy 2 |
| `matplotlib.pyplot` | `plot` (строки формата), `scatter`, `bar`, `barh`, `hist`, `title`, `xlabel`, `ylabel`, `grid`, `legend`, `xlim`, `ylim`, `axis`, `show`, `pause`, `figure`, `clf`, `cla`, `close`, `subplots()` с одной областью |

Встроенные функции: `float`, `abs`, `round` (до чётного, как Python), `pow` (в том числе с модулем), `min`, `max`, `sum`, `bool`. Синтаксис: `import a`, `import a as b`, `import a.b`, `from a import x, y as z`, `from a import *`, обращения через точку, именованные аргументы (и у своих функций), кортежи, срезы, `a, b = b, a`, `+=` и другие составные присваивания, методы списков, декоратор `@task`, `if __name__ == "__main__":`.

## Как это устроено

- Интерпретатор остался собственным (`src/pythonRuntime.ts`, `src/pythonExecution.ts`), библиотеки — в `src/python/`. Старые программы дают то же дерево разбора и те же значения: ключи учебных доказательств и сравнение заготовки с решением не меняются.
- Программа выполняется целиком в песочнице (сервер — `server/b2b/runner-entry.ts`, примеры уроков и справка — в браузере тем же кодом). Всё видимое записывается в сцену с виртуальным временем (`src/python/scene.ts`): скорость черепахи, `time.sleep`, шаги Робота, `plt.pause`. Страница воспроизводит сцену (`src/b2b/SceneView.tsx`): «Остановить», «Сразу результат», «Показать анимацию снова». Новый запуск создаёт новые модули: черепаха, поле, графики и случайные числа не переносятся.
- Строки вывода получают моменты появления, поэтому печать идёт синхронно с анимацией.

## Проверка заданий

Каждый тест может указать `checks` и `world`:

- `output` — текст вывода (как раньше; тест без `checks` проверяется только так);
- `drawing` — итоговый рисунок совпадает с рисунком эталона, запущенного на тех же данных: растровое сравнение линий, заливок и точек с допуском 3 % и соседней клеткой 2 пикселя, плюс надписи (текст, координаты, выравнивание, размер и оформление), штампы (форма, координаты, размер и направление) и фон. Порядок рисования неважен. Чёрный цвет по умолчанию не ограничивает выбранный учеником цвет. Пустой итог после clear/reset не засчитывается. Сравнение ограничено бюджетом 400 000 шагов обработки геометрии; слишком большой или сложный рисунок отклоняется с объяснением, без усечения и ложного успеха;
- `robot` — на поле `world` закрашены все `*`, нет лишних закрашенных, Робот на парковке `P` (если есть), без столкновений;
- `plot` — показанные рисунки совпадают с эталоном по видам графиков и данным; заголовок, подписи осей, сетка, легенда, границы и подписи наборов — если их задаёт эталон.

Эталон запускается внутри той же песочницы, ученику он не передаётся. Открытый тест при ошибке показывает понятную причину и картинку «Должно получиться», скрытый — без подробностей. Результат проверки хранит рисунок ученика (до 400 КБ) для журнала. В конструкторе задания у каждого теста есть флажки «Что проверять» и текстовое поле Робота с предпросмотром; формат поля описан в `src/python/robotWorld.ts`.

Поле `world`, заданное преподавателем, неизменно для программы ученика: `set_field_size`, `goto`, `put_wall`, `set_cell_type` и `set_parking_cell` отказывают с объяснением. Команды настройки остаются доступны в самостоятельной программе, у которой нет заданного поля.

## Обновление существующей школы

Изменился проверяющий интерпретатор, поэтому меняется отпечаток среды проверки (`.runner/runtime.json`). Как и при любом изменении интерпретатора:

```powershell
npm run build
node scripts/reverify-published.mjs --dry-run
node scripts/reverify-published.mjs
```

До повторного подтверждения новые решения по ранее опубликованным версиям принимаются и ждут («Kodik обновил проверяющую среду»), после подтверждения проверяются. Тесты, ответы, попытки и оценки не переписываются. Прежние задания, Blockly и прогресс работают как раньше: совместимость подтверждена прежними проверками проекта и сверкой с CPython.

## Ограничения

Числовые параметры Черепахи, данные и настройки графиков принимают только конечные числа: NaN и Infinity отклоняются, а не превращаются в нули при передаче сцены. Для xlim/ylim указываются обе границы, для axis — четыре разные попарно границы. Паузы должны быть конечными и неотрицательными.

Точный список — в справке. Главное: программа сначала выполняется целиком, затем воспроизводится, поэтому нет событий клавиатуры и мыши, `textinput`, `ontimer`; паузы `time.sleep` и `plt.pause` вместе — до 60 секунд; 100 000 операций для программ с библиотеками (10 000 без них, как раньше); массивы до 10 000 элементов; поле Робота до 20×20 и 5000 шагов; до 8000 фигур черепахи и 20 000 точек графиков. Последняя значащая цифра `sin`/`cos` может отличаться от Python на конкретном компьютере. Не поддерживаются классы, словари, f-строки, генераторы списков, `break`/`continue`, `in`, `numpy.random`, несколько областей графика и `savefig`.
