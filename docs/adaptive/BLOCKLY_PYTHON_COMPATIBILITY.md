# Совместимость блоков Blockly и учебного Python

Источник истины — `BLOCKS` и `UNSUPPORTED_REASONS` в `src/adaptive/blockProgram.ts` (транслятор `blocks-py/0.1`). Каждая строка «PoC» покрыта тестом `tests/adaptive-blockly.poc.ts`: генерация, исполнение существующим `grade()`. Для программ-образцов вывод сверен с CPython 3.11.9 (7 программ совпали).

## 1. Поддерживаемые блоки — PoC

| Категория | Блок (тип) | Подпись | Python | Навык | Примечания |
|---|---|---|---|---|---|
| Ввод и вывод | `text_print` | напечатать | `print(x)` | Вывод | Одно значение. Несколько — через «соединить» |
| | `kodik_input_int` | ввести целое число | `int(input())` | Ввод | Новый блок. Без подсказки: её текст попал бы в вывод и сломал тесты |
| | `kodik_input_text` | ввести текст | `input()` | Ввод | Новый блок |
| Переменные | `variables_set` | присвоить | `x = …` | Переменные | Имя проверяется по правилам интерпретатора |
| | `variables_get` | значение переменной | `x` | Переменные | Предупреждение, если используется до присваивания |
| | `math_change` | увеличить на | `x = x + d` | Переменные | **Вместо `+=`**, которого нет в интерпретаторе |
| Числа | `math_number` | число | `5`, `(-3)`, `2.5` | Арифметика | До 10¹² по модулю, отрицательные в скобках |
| | `math_arithmetic` | + − × ÷ степень | `+ - * / **` | Арифметика | `/` даёт дробь, как в Python 3 |
| | `math_modulo` | остаток от деления | `a % b` | Арифметика | |
| Текст | `text` | текст | `"…"` | Строки | До 500 символов; экранирование `"` `\` и переводов строки |
| | `text_join` | соединить | `"a" + str(b)` | Строки | 0–10 частей; нетекстовые части оборачиваются в `str()` |
| | `text_length` | длина | `len(x)` | Строки | |
| Условия | `logic_compare` | сравнить | `== != < <= > >=` | Сравнения | |
| | `logic_operation` | и / или | `and`, `or` | Логика | |
| | `logic_negate` | не | `not x` | Логика | |
| | `logic_boolean` | истина / ложь | `True`, `False` | Логика | |
| | `controls_if` | если / иначе если / иначе | `if/elif/else` | Условия | До 20 веток `elif`; пустая ветка → `pass` и предупреждение |
| Циклы | `controls_repeat_ext` | повторить N раз | `for _kodik_i1 in range(N):` | Циклы | Счётчики `_kodik_iN`, уникальны по вложенности. Имена с `_` ученикам запрещены |
| | `controls_whileUntil` | повторять пока / до | `while c:` / `while not (c):` | Циклы | Бесконечный цикл останавливается лимитом интерпретатора (10 000 шагов) |
| Функции | `kodik_define` | создать функцию | `def f():` | Функции | Без параметров; только на верхнем уровне; определяется до основной программы |
| | `kodik_call` | вызвать функцию | `f()` | Функции | Ошибка, если функция не создана |

Вложенные выражения всегда берутся в скобки: `(n % 2) == 0`. Это исключает ошибки приоритета ценой лишних скобок. Убирать скобки там, где приоритет очевиден, — улучшение для читаемости, **План**.

## 2. Блоки Blockly без соответствия — отказ с объяснением

| Блок | Причина | Статус |
|---|---|---|
| `controls_flow_statements` (break, continue) | Нет в интерпретаторе | Отложено до расширения интерпретатора (PD-12) |
| `controls_for` (от … до … шаг) | Семантика включительного диапазона и отрицательного шага требует отдельной проверки | План, v2 |
| `controls_forEach`, `lists_*` | Списки не поддержаны блоками | Отложено |
| `math_single`, `math_round` | `abs`, `round` и т. п. нет в интерпретаторе | Отложено |
| `text_prompt_ext` | Подсказка попадает в вывод | Заменён блоками Kodik |
| `procedures_defreturn`, `procedures_defnoreturn` | Параметры и return пока не проверены для блоков | План, v2 (интерпретатор их поддерживает) |
| Любой другой тип | «Блок «…» не поддерживается» | — |

## 3. Python → блоки: анализ эталона — PoC

`analyzeReference()` разбирает эталон тем же парсером, что и сервер. Он предлагает навыки и палитру, а для несовместимых конструкций объясняет причину.

| Конструкция в эталоне | Результат |
|---|---|
| `n = int(input())`, `print(…)`, арифметика, `%`, сравнения, `and/or/not` | Совместимо |
| `if/elif/else`, `while` | Совместимо |
| `for _ in range(n)` без использования счётчика | Совместимо: «повторить N раз» |
| `x = x + 1` | Совместимо: в палитру добавляется «увеличить на» |
| `"Привет, " + name`, `str(x)` в сцеплении | Совместимо: «соединить» |
| `def f():` без параметров и вызов `f()` | Совместимо |
| `for i in range(n): print(i)` — счётчик используется | **Нет**: «Цикл for со счётчиком… пока не имеет блока» |
| `range(a, b)`, `range(a, b, step)` | **Нет**, та же причина |
| Списки, индексы, присваивание по индексу | **Нет** |
| `def f(x): return …` | **Нет**: параметры и return — только Python |
| `//` | **Нет**: блока целочисленного деления нет |
| `1 < x < 5` | **Нет**: предложено разбить на два сравнения с «и» |
| `print(a, b)` | **Нет**: предложено соединить в одну строку |
| `input("Подсказка")` | **Нет**: подсказка попала бы в вывод |
| Эталон не разбирается (`+=`, `break` и т. п.) | **Нет**, с текстом ошибки парсера |

Анализ — подсказка, а не педагогическая цель. Навыки подтверждает преподаватель (ADAPTIVE_UX_SPEC.md).

## 4. Лимиты и защита — PoC

| Проверка | Лимит или поведение |
|---|---|
| Размер JSON | 100 000 символов |
| Число блоков | 200 (как в B2C) |
| Глубина вложенности | 12 |
| Текст в блоке | 500 символов |
| Имя переменной или функции | 40 символов; правила имён интерпретатора; служебные слова и встроенные функции запрещены; нельзя начинать с `_` |
| Ветки `elif` | 20 |
| Части «соединить» | 10 |
| Мусор вместо программы (`null`, число, строка, массив, блок без типа) | Отказ без исключения |
| Циклическая ссылка блоков (`next` указывает на себя) | Отказ: «блоки ссылаются сами на себя». **Найдено и исправлено тестом** |
| Блок значения на месте команды и наоборот | Отказ с объяснением |
| Блок вне палитры задания | Отказ: «не входит в набор этого задания» |
| Отключённый блок | Пропускается, как в Blockly |
| Несколько групп команд | Выполняются сверху вниз; предупреждение |
| Исполнение | Лимиты существующего интерпретатора и процесса (время, память, вывод) не меняются |
