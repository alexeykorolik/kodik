# Отчёт о проверках адаптивного обучения

Три вида проверок не смешиваются:
1. автоматические;
2. технические, выполненные разработчиком;
3. исследования с людьми.

**Исследований с людьми не было.**

## 3. Исследования с людьми — запланированы

**Преподаватель (этап 6):** сам создаёт три задания — переменные и арифметика, условия, циклы. По каждому:
- создание;
- понятность анализа эталона и навыков;
- настройка палитры;
- предпросмотр трёх режимов;
- публикация;
- прохождение в нескольких режимах;
- правильность проверки.

Метрики:
- самостоятельное завершение;
- время;
- ошибки и возвраты;
- непонятные слова («палитра», «навык», «режим»);
- согласие с порогами правил (ADAPTIVE_RULES.md §6).

**Ученики:** ограниченный тест только после условий школы (PILOT_READINESS_CHECKLIST.md). Наблюдаем:
- понятен ли переход между режимами без объяснений;
- читают ли Python-зеркало;
- реакцию на рекомендации;
- время до первого запуска в каждом режиме.

Статистика по 1–3 участникам не считается.

**Нагрузка:** класс из 15–30 демо-учеников с блоками и Python — локально (`pilot-load` с блоковыми попытками), затем на целевом сервере. Не проводилось: серверного API для блоков ещё нет.
