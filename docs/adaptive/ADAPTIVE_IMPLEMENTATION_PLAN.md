## Риски

| Риск | Вероятность | Мера |
|---|---|---|
| Ограничения интерпретатора делают многие школьные задачи несовместимыми с блоками (счётчик в `for`, `print(a, b)`) | Высокая | Анализ эталона объясняет причину; задание остаётся в Python. Приоритет — блок `controls_for` и `print` с несколькими значениями после расширения интерпретатора (PD-12) |
| Расхождение клиентской и серверной трансляции | Низкая | Один исходник, один бандл; версия транслятора в попытке и в снимке задания |
| Blockly недоступен с клавиатуры для части учеников | Средняя | Проверить клавиатурную навигацию Blockly 12 (встроенная фокусировка или официальный плагин) на этапе 3; Python-режим всегда разрешён |
| Учитель воспринимает анализ эталона как автоматическую цель | Средняя | Навыки помечены «проверьте», подтверждаются явно |
| Ученики массово переписывают код из зеркала в Python | Средняя | Это и есть ознакомление. Самостоятельность подтверждается следующим, **другим** заданием (правило переноса) |
| Нагрузка: трансляция в исполнителе | Низкая | Трансляция — миллисекунды на фоне запуска процесса. Повторить `pilot-load` с блоками на этапе 3 |

## Регрессия на каждом этапе

`npm run build` · `npm run test:smoke` · `npm run test:pilot` · `tsx tests/adaptive-blockly.poc.ts` (станет частью `test:pilot`) · `playwright test --config playwright.b2b.config.ts` · перед слиянием `npm run check:critical`. При любом изменении интерпретатора — сравнения с CPython. Нагрузочный тест класса 15–30 демо-учеников с блоками — сначала локально, затем на целевом сервере.
