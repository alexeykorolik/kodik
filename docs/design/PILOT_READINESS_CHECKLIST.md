# Готовность к первому уроку в гимназии

Чек-лист для класса из 15–30 учеников. Дополняет общий реестр [PILOT_READINESS.md](../../PILOT_READINESS.md): тот отвечает за коммерческую готовность, этот — за конкретный урок.

Отметки:
- ✅ — проверено автоматическими тестами на рабочей сборке **локально**, 19 октября 2026, `npm run test:pilot`: 45 тестов, 70 сравнений с CPython, код 0;
- ⬜ — ещё не проверено;
- 🔶 — требует решения или условий школы.

Локальные тесты не заменяют проверку на целевом сервере и в сети школы.

## 4. Во время урока: наблюдение

Проводится отдельно и только после выполнения раздела 1. Сценарий — UX_TEST_REPORT.md, сценарий B. Собираем время до первого запуска, число обращений за помощью, ошибки входа и непонятные сообщения. Медленных проверок (> 5 с) и сбоев смотрим по журналу сервера.
