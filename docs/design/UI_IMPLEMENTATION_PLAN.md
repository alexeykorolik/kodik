**Условие старта:** итоговые макеты согласованы с UX/UI-дизайнером и владельцем Kodik. До этого в `src/` нет масштабных изменений. Исходная B2C-версия (`?legacy=1`, `src/designSystem.css`, Android-сборка) не меняется.

## 3. Поэтапное внедрение

Порядок задан ТЗ. Каждый этап — отдельная ветка и PR, который можно откатить, не трогая соседние.

| # | Этап | Состав | Файлы |
|---|---|---|---|
| 1 | Токены и общие компоненты | `src/b2b/ui/`:<br>• `tokens.css` из прототипа;<br>• Button, Field, Select, Switch, Tag, Table, Modal, ConfirmDialog, Toast, Tabs, Skeleton, EmptyState, SaveIndicator, Logo, Icon.<br>`Badge / Empty / Header / Glyph` переводятся на них с прежним API | новые + `App.tsx` (импорты) |
| 2 | Оболочка и навигация преподавателя | Сайдбар 5 пунктов + «Школа» (только admin), рейка < 1200 px, `min-width: 1024px`, логотип из SVG | `App.tsx` (оболочка), `styles.css` (удаление старой оболочки) |
| 3 | Конструктор заданий | Новый `builder/`. Логика `useMaterialDraft`, проверки качества и публикации — без изменений, меняется только разметка | `Builder.tsx` → `builder/*` |
| 4 | Рабочая среда ученика | `Workspace` в новой раскладке; тот же компонент в предпросмотре конструктора | `Workspace.tsx`, `MinimalCodeEditor.tsx` (стили) |
| 5 | Курсы, группы, результаты | Страница группы, матрица, панель решения, пакетное создание учеников | вынос из `App.tsx` в `teacher/*` |
| 6 | Административные разделы | «Школа»: преподаватели, ученики, доступ, пароли | вынос из `App.tsx` |

`App.tsx` (1761 строка) и `styles.css` (2297 строк) не переписываются за один раз. На каждом этапе из них уходит только переносимый экран. Старые CSS-классы удаляются, когда у них не осталось потребителей; проверка — `grep` по классу.

## 4. Проверки на каждом этапе

| Проверка | Команда / способ |
|---|---|
| Сборка и типы | `npm run build` |
| API-контракты не изменились | `npm run test:pilot` (45 тестов, 70 сравнений с CPython) |
| Права и изоляция | `tests/b2b.integration.mjs` в составе `test:pilot`; на этапах 5–6 — ручной вход каждой ролью |
| B2B end-to-end | `npx playwright test --config playwright.b2b.config.ts`: тексты кнопок сохраняются или сценарии обновляются в том же PR |
| Исходный курс не сломан | `npm run test:smoke` и legacy-сценарии из `check:critical` |
| Обновление страницы и прямые маршруты | Открыть `#builder/:id`, `#assignment/:id`, `#groups/:id`, `#results` по ссылке и через F5 под каждой ролью |
| Размеры и клавиатура | Скрипт ревью прототипа, адаптированный под сборку: 5 размеров, Tab-порядок, модальные окна |
| Учебный движок | Не меняется. Исключение — PD-12, отдельная задача с полным прогоном сравнений |

Перед слиянием этапа — полный `npm run check:critical`.

## 5. Риски

| Риск | Мера |
|---|---|
| Перенос экрана ломает соседние: общий `App.tsx` | Один экран за PR, старые классы удаляются последними |
| e2e завязаны на тексты | Сохранять тексты действий или обновлять сценарии в том же PR |
| Шрифты из Google Fonts недоступны в сети школы | Nunito уже в `public/fonts`, туда же JetBrains Mono |
| Учителя пишут эталоны с неподдерживаемыми конструкциями | Справка в конструкторе + стартовые уроки в поддерживаемом подмножестве |
| Прототип принят за готовый продукт | Метка «прототип на согласование» на каждом экране, данные помечены как пример |
