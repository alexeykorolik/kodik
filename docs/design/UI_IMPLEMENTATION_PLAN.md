# План внедрения UI Kodik B2B

**Условие старта:** визуальное направление утверждено UX/UI-дизайнером и владельцем Kodik (дополнение к ТЗ, п. 5). До этого в `src/` ничего не меняется.

## Архитектура

Принцип: оформление меняется поверх существующей логики. Сервер, API, хуки черновиков и очередь проверок не меняются.

```
src/b2b/
  ui/                    ← новое: дизайн-система
    tokens.css           ← из docs/design/prototype/tokens.css
    base.css             ← сброс, типографика, фокус
    Button.tsx  Field.tsx  Select.tsx  Switch.tsx  Tag.tsx  Table.tsx
    Card.tsx  Modal.tsx  ConfirmDialog.tsx  Toast.tsx  Tabs.tsx
    Skeleton.tsx  EmptyState.tsx  SaveIndicator.tsx  Logo.tsx  Icon.tsx
  teacher/               ← экраны преподавателя, вынесенные из App.tsx
    Overview.tsx  Courses.tsx  CourseStructure.tsx  Groups.tsx  Group.tsx
    Results.tsx  AttemptDrawer.tsx  School.tsx  Onboarding.tsx
  builder/               ← конструктор
    Builder.tsx (оболочка, шаги)  TypeStep.tsx  InfoStep.tsx  ContentStep.tsx
    EditorStep.tsx  CheckStep.tsx (TestCaseTable, VerifyPanel)  PublishStep.tsx
    LivePreview.tsx (обёртка над Workspace)
  student/
    Home.tsx  CoursePath.tsx  Progress.tsx
    Workspace.tsx (существующий, новая раскладка)  HintLadder.tsx  Console.tsx
  App.tsx                ← роутинг и загрузка состояния, без разметки экранов
```

- `Badge`, `Empty`, `Header`, `Glyph` из `App.tsx` получают реализацию из `ui/` с тем же API: экраны переключаются по одному.
- `styles.css` (2297 строк) удаляется по мере переноса экранов. Новый CSS — только через токены (правило линтера: запрет HEX вне `tokens.css`).
- Логика проверки Python (`grader.mjs`, `pythonRuntime.ts`, `learningRules`) не импортируется компонентами напрямую — только через `api.ts` и хуки.
- Исходный курс (`?legacy=1`, B2C) и `src/designSystem.css` не трогаем.

## Этапы

| # | Этап | Состав | Проверка |
|---|---|---|---|
| 0 | Согласование | Ревью прототипа, правки палитры и шкалы | Подпись дизайнера и владельца |
| 1 | Основа | `ui/` + токены + Nunito/JetBrains Mono (локально в `public/fonts`) + Logo из SVG. Оболочка преподавателя: сайдбар 5 пунктов + «Школа» | Существующие `test:b2b:ui` проходят без правок сценариев (селекторы по ролям и текстам) |
| 2 | Конструктор | Рейка шагов, шаг «Тип», живой предпросмотр через `Workspace`, таблица тестов, панель проверки качества человеческим языком, индикатор сохранения, защита от ухода | `task-quality.e2e.ts`, `b2b.e2e.ts` + новый сценарий «слабые тесты → исправление → публикация» |
| 3 | Среда ученика | Без сайдбара, изменяемые панели, фокус-режим, лестница подсказок, вкладка «Тесты», понятные ошибки. Мобильная клавиатура скрыта на десктопе | `pilot.e2e.ts`, `curriculum.e2e.ts`; клавиатура: Tab/Esc/Ctrl+Enter |
| 4 | Главная ученика и прогресс | «Продолжить» ведёт к конкретному заданию/шагу; навыки из `learningRules` | Новый e2e: вход ученика → 1 клик до редактора |
| 5 | Обзор преподавателя | «Требуют внимания», группы, продолжить работу, активность, онбординг-чек-лист | Серверный тест нового запроса «внимание» с изоляцией школ |
| 6 | Группы и результаты | Страница группы с вкладками, матрица с фильтром, боковая панель решения, массовое создание учеников | `b2b.integration.mjs` + тест пакетного создания с лимитом |
| 7 | Школа | Преподаватели; блок подписки — пустое состояние до появления данных | Нет фиктивных цифр в DOM (проверка e2e) |
| 8 | Проверка | Матрица 4 размеров × ключевые экраны, axe-core на всех экранах, UX-тест с преподавателем | `UX_TEST_REPORT.md` |

Порядок 2 → 3 выбран потому, что конструктор — главный приоритет ТЗ, а его предпросмотр использует ту же `Workspace`. Изменения среды ученика сразу видны в обоих местах.

## Риски

| Риск | Мера |
|---|---|
| Большой `App.tsx` и общие стили — перенос ломает соседние экраны | Перенос по одному экрану, старые классы удаляются только после переноса всех потребителей |
| Playwright-сценарии завязаны на тексты кнопок | Сохранять тексты действий («Проверить решение», «Опубликовать») или обновлять сценарии в том же коммите |
| Nunito с Google Fonts недоступен в школьной сети | Шрифты локально в `public/fonts` (Nunito уже там) |
| Ожидание «Скоро» для Blockly воспринимается как обещание | Подпись «Пока доступно в исходном курсе Kodik», без даты |
