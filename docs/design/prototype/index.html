      Изменения не сохранены на сервере

      Последние правки хранятся только в этом браузере. Если уйти сейчас, они восстановятся при следующем открытии на этом компьютере.

      Что умеет учебный Python Kodik

      Это собственный учебный интерпретатор, не CPython. Он запускается на сервере с ограничением времени и вывода. Если эталон использует неподдерживаемую конструкцию, проверка качества сразу это покажет.

      Поддерживается

      • print, input, int, str, len, range
      • Числа, строки, True/False/None, списки и индексы a[0]
      • + − * / // % ** и сравнения, в том числе цепочкой 1 < x < 5
      • and, or, not
      • if / elif / else, for … in range / по списку, while
      • def, return, параметры; pass; комментарии
      • Отступ ровно 4 пробела

      Пока нет

      • += и другие сокращения
      • break, continue
      • print(…, end=…), sep=
      • f-строки, методы .append(), .split(), .upper()
      • Срезы s[1:3], оператор in
      • float, max, min, abs, round, sum, list
      • Словари, кортежи, import, class, try

      Ограничения: до 250 строк, до 10 000 шагов выполнения. Бесконечный цикл остановится с понятным сообщением.

      Отключить доступ?

      Человек сразу выйдет из всех сессий и не сможет войти. Решения, попытки и членство в группах сохранятся. Доступ можно включить обратно.
