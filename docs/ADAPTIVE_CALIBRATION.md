## Изменения

- Задания23–100: неизвестный навык или минимальный score<0.40 → заполнение кода;0.40–0.72 → сборка частей;≥0.72 и минимум2самостоятельных подтверждения по каждому используемому навыку → свободный код. Уже выбранный формат изменяется максимум на одну ступень; повышения требуют свежих подтверждений. При открытии помощь может увеличиться до ошибок. Незавершённая сохранённая сессия сохраняет формат, пропуск и ответ.
-100основных заданий получили постоянные ключи. У78расширенных заданий ID/key записаны явно в seed. ID короткой практики тоже закреплены, прежние отрицательные номера сохранены. Перестановка массива не перенумеровывает прогресс, objectives, scaffolds или ссылки практики. История numericID продолжает работать.
- `scaffoldForSkill`: input()/int(input()), правая часть присваивания (предпочтение обновлению), условие, range/while, return/вызов, индекс/итерация/len, команды рисования. Пропуск строится для наиболее слабого используемого навыка, с откатом к primarySkill, если выбранной конструкции нет в программе. Фактический навык пропуска сохраняется в сессии. Четыре прежних вводных completion-draft сохраняют свой пропуск.
- События получают curriculumVersion=`2026-10-01.2`, appVersion=SHAсборки. Сервер проверяет формат версии и сам находит lesson_key по ID; присланный клиентом ключ игнорируется. Старые события очереди и строки базы — отдельная `legacy`-выборка. Изменение кода/правил курса требует повышения версии курса и сохранения прежней версии в allowlist, если её офлайн-события ещё могут приходить.
- Некорректный Python сравнивается по токенам: пробелы вокруг токенов/комментарии не дают нового evidence, содержимое строк, границы имён и отступы сохраняются. Валидный код продолжает сравниваться по AST.
- SQL отчёта считает Support Independence Rate по одному запуску задания, включая reload и исключая восстановление помощи. Подсказки/готовое решение и формат отражаются в completion. Пустой CSV/протокол дополнены версиями и отдельной новой transfer-задачей. Это подготовка измерения, не результаты обучения.
