# Обновление основного курса Kodik

В проекте один основной маршрут: 100 заданий, 12 глав. Первые 22 урока сохранены вместе с переходом от блоков к самостоятельному Python. Добавлены 78 новых задач на строки и вычисления, условия, циклы, функции с аргументами, списки, ввод и рисунки. Темы взяты за основу из исходного Word-документа; новые задачи оформлены через общий экран урока. Отдельный прежний курс убран из навигации.

Мобильная страница закреплена по высоте окна. Карта разбита на страницы с переключением глав. Длинный код, содержание справки и результаты просматриваются внутри своих областей. При появлении системной клавиатуры для Python редактор подстраивается под доступную высоту. Поля текста и чисел в Blockly на сенсорном телефоне открывают собственную клавиатуру Kodik с русской и английской раскладками.

Новые темы имеют разбор и пример. Для параметров функции, списка, input и первой команды рисования используются вводные задания с готовым каркасом. Остальные задачи продолжают самостоятельный ввод, освоенный к концу исходных уроков. Проверка сравнивает результат программы; ввод проверяется на нескольких наборах данных, рисунки — по отрезкам. Допускаются другие имена переменных и кавычки.

Проверено:

- Все 22 исходных задания через Blockly и учебный движок.
- Все 78 новых решений, альтернативные имена и кавычки, отклонение пустых ответов.
- Все 100 шагов последовательно через интерфейс до финального экрана.
- Сохранение и восстановление прогресса, ошибки, подсказки и повторные проверки.
- Мобильные экраны, сжатая область при вводе, клавиатура Kodik и рисунок.
- Производственная сборка и серверная сборка AI Tutor.

Мобильные проверки выполнены в браузерной эмуляции. Физическое устройство с Safari в этой среде недоступно.

Исходники нового курса: `src/extendedCourse.ts`. Разборы: `src/courseMaterials.ts`. Снимки: `docs/mobile-ux/`.
