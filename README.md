# Kodik — один курс Python из 100 заданий

Мобильный учебный прототип на React/TypeScript: 12 глав, путь от Blockly через Python с поддержкой до самостоятельного кода. Production: https://kodiknew.vercel.app . Репозиторий: https://github.com/alexeykorolik/kodik .

## Запуск и проверки

```powershell
npm install
npm run dev
npm run test:smoke
npm run build
npm run test:ui
```

`npm run local` собирает приложение и открывает локальный preview на 127.0.0.1:4173. Playwright использует установленный Edge. `KODIK_TEST_URL` задаёт адрес внешнего стенда. Физические телефоны и настоящие ученики проверяются отдельно, по `docs/PILOT_PROTOCOL.md`.

## Единственный учебный маршрут

`src/course.ts` объединяет `courseBase.ts` (первые22упражнения) и `extendedCourse.ts` (23–100). Материалы: `courseMaterials.ts`. Точные цели каждого нового упражнения и структурные ограничения: `lessonObjectives.ts`. Старые отдельные Course100, JSON и эталоны удалены. Старые QA-документы описывают исторические версии; актуальный отчёт — `docs/AUDIT_IMPLEMENTATION.md`.

Первые22упражнения используют Blockly → IR → Python и базовый интерпретатор `learningEngine.ts`/`textLearning.ts`. Продвинутые задания используют `pythonRuntime.ts` (AST parser), `pythonExecution.ts` (ограниченный запуск), `pythonStructure.ts` и `extendedChecker.ts` (проверка). Код не исполняется через eval, не импортирует модули, не имеет доступа к файлам/ОС/сети. Лимиты:10000операций,1000значений range,500строк/линий,40вложенных вызовов, числовые значения до10¹².

Структурная проверка учитывает зависимости, которые достигли вывода или рисунка: мёртвый/неиспользуемый/перезаписанный код не даёт evidence. Дополнительные входы, изменения данных и вызовы функций с другими аргументами проверяют обобщение. Это учебный checker с заданными ограничениями, а не доказательство эквивалентности произвольных программ.

## Адаптация и прогресс

`skills.ts`/`mastery.ts` описывают навыки и evidence. `adaptiveSupport.ts`, `learningFlow.ts`, `supportVariants.ts` решают, какую поддержку предложить. Продвинутые задания поддерживают guided_code → code_tokens → free_code; к Blockly не возвращаются. Два содержательно разных ошибочных решения могут вызвать короткую практику с возвратом в тот же урок. Повтор одной проверки или изменение только пробелов не создаёт новое evidence. `practicePool.ts` содержит подготовленные упражнения, включая списки, ввод и рисование; AI их не генерирует.

Разбор темы в заданиях23–100 бесплатен. Подсказки именно по решению учитываются в звёздах. На экране прогресса первыми показаны навыки; история ошибок и оценки первой проверки доступны в отдельных вкладках. Исправленные ошибки и исходные первые оценки сохраняются. Старую отсутствующую историю приложение не выдумывает.

`progress.ts` хранит прогресс версии4 по прежнему ключу kodik-progress-v1. Прежние завершения, совместимые черновики и звёзды сохраняются. Account пока сохраняет имя локально; полноценный вход между устройствами не реализован.

## AI Tutor

Серверный endpoint `/api/ai/tutor`, provider Groq или OpenAI, флаги `AI_TUTOR_ENABLED`, `AI_EXAMPLES_ENABLED`, `AI_EXPLANATIONS_ENABLED`; клиентские флаги из `.env.example`. Секретные ключи доступны только серверу. AI получает структурный контекст, включая while/function/return/list/input/drawing; конкретные значения и имена ученика/код не отправляются. Ответ проходит validator; при недоступности AI используется подготовленная помощь. AI не меняет оценки и учебный маршрут.

Квоты хранятся атомарно в Supabase и общие для всех Vercel instances:8запросов на урок/ученика в UTC сутки,30/мин по адресу,80/сутки на ученика,200/сутки по адресу,1000/сутки на приложение. Последние три лимита настраиваются `AI_LEARNER_DAILY_LIMIT`, `AI_IP_DAILY_LIMIT`, `AI_DAILY_REQUEST_LIMIT`. Cookie HttpOnly/Secure подписан; IP хранится только как HMAC bucket. При сбое хранилища AI-запрос не отправляется. Локальный дневной счётчик переживает reload и нужен только для удобства; серверная квота авторитетна. Бесплатность Groq не означает отсутствие квот провайдера.

## Анонимная аналитика

`VITE_ANALYTICS_ENABLED=true` включает `/api/events`. Серверу нужны `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` (или SUPABASE_SECRET_KEY). Миграция003 создаёт learning_events и learning_budgets, закрытые RLS для anon/authenticated. Применение миграции — администратором либо одноразовым provisioning из авторизованного Vercel окружения. Постоянного административного endpoint нет.

События: открытие, первое действие, проверки, подсказки/AI, смена поддержки, практика, завершение и время выполнения. У каждого события UUID, анонимные learner/session ID; события идемпотентны. Сервер заново очищает поля: нет исходного кода, ответов, имени, email или текста ошибок. IP не записывается в события. Локальная очередь до5000событий отправляет пачки до40, переживает reload/потерю сети; последние500событий доступны для локальной выгрузки. Переполнение очереди удаляет самые старые события, поэтому это не гарантированное долговременное хранилище при длительной работе без сети. Аналитика никогда не блокирует урок.

Необязательная синхронизация учебного прогресса — отдельный механизм: миграции001/002, Anonymous Sign-ins и `VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY`. Она не включается автоматически вместе с аналитикой. Черновики остаются локальными; учебный ответ может входить в синхронизируемое учебное состояние. Вход с другого устройства пока отсутствует.

## Интерфейс

Фиксированная внешняя страница, внутренние области редактора/диалогов; мобильная навигация из4разделов. Blockly использует клавиатуру Kodik для полей. Текстовый Python использует системную клавиатуру с собственной панелью Tab,( ),:,кавычки и подсветкой. SVG и локальный Nunito. Загруженный урок работает без сети; первый запуск офлайн без service worker не поддерживается.
