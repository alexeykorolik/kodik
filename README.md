# Кодик — обучение Python и 100 заданий

Учебное приложение на React и TypeScript. Сохранён исходный курс на Blockly из 22 упражнений в 5 главах. Добавлен курс из 100 заданий в 12 главах по материалам `Kodik_100_zadaniy_i_materialy.docx`: от первого `print` до списков, ввода и рисунков черепашки.

## Запуск

```powershell
npm.cmd install
npm.cmd run local
```

Production-сборка: **http://127.0.0.1:4173/**. Скрипт собирает приложение и запускает скрытый фоновый preview только на этом компьютере. Логи: `local-server.log`, `local-server-error.log`; PID: `local-server.pid`. Занятый порт не освобождается автоматически: можно выбрать `npm.cmd run local -- 4174`.

Разработка: `npm.cmd run dev`. После изменений выполните `npm.cmd run build`: уже работающий preview подхватит новую сборку. Прогресс привязан к браузеру и адресу.

## Курс из 100 заданий

Откройте его кнопкой на главной странице или перейдите на `/?course=100`. Задания идут по порядку; в карте видны 12 глав, завершение и лучшие звёзды. Содержимое всех карточек — условие, входные данные, ожидаемый результат, три подсказки, материал и навыки — хранится в `src/course100.json`. Эталонные решения находятся в `src/course100Solutions.ts` и показываются ученику только после раскрытия трёх подсказок.

Новый курс использует плитки команд, сборку строк и редактор Python в зависимости от стартового формата задания. Это отдельный путь обучения; исходный курс из 22 упражнений по-прежнему использует Blockly. Проверка запускает ограниченное подмножество Python в браузере: арифметику, условия, циклы `for` и `while`, функции с параметрами и `return`, списки, ввод и команды черепашки. Пользовательский код не получает доступ к сети, файлам или ОС. Для заданий с вводом проверка использует данные из условия и дополнительный набор значений; рисунки проверяются по геометрии линий. Прогресс нового курса хранится локально под отдельным ключом `kodik-course-100-v1`, чтобы не смешивать его с исходным курсом.

Звёзды отражают попытки и подсказки конкретного прохождения. Освоение навыков хранится отдельно и влияет на формат поддержки; две последовательные ошибки уменьшают поддержку на один шаг и предлагают короткое повторение уже пройденного задания. Следующие задания открываются по порядку, без порога звёзд.

## Обучение

Первое упражнение начинается с пустого поля: добавить команду печати, отдельно добавить текст, изменить значение, увидеть Python и проверить результат. Каждая новая механика получает пошаговое знакомство. Уже освоенные знакомства автоматически не повторяются. Библиотека открывается постепенно; текущий шаг выделяет нужную кнопку или поле.

Python обновляется вместе с блоками и подсвечивает строку, связанную с выбранным блоком. На мобильном вспомогательный код свёрнут в компактную панель; в заданиях про связь блоков и синтаксиса он остаётся центральной частью. Есть распознавание строки, заполнение пропуска, сборка синтаксиса и самостоятельный ввод программ с переменными, условиями, циклами и функциями.

Мобильный урок: короткое задание → большая рабочая область → одна нижняя кнопка. «+ Блок» открывает только доступные элементы; «Python → Посмотреть» открывает отдельный нижний лист. Длинные объяснения доступны через «Подробнее», содержательные подсказки раскрываются по одному уровню. Ошибка не накрывает редактор: «Проверить снова» сразу проверяет актуальное решение. Самостоятельный код вводится в простом поле с номерами строк; отступ — Tab, выход назад — Shift+Tab. Safe-area и `visualViewport` учитываются при размещении ввода и кнопки. Экранная клавиатура проверена автоматическими эмуляциями геометрии, не на физических телефонах. Подробности — `MOBILE_REDESIGN_REPORT.md`.

10 знакомств проходят без оценки. 12 самостоятельных упражнений дают до 36 звёзд:

- 3 звезды: первая успешная проверка без подсказок.
- 2 звезды: вторая/третья проверка либо одна содержательная подсказка.
- 1 звезда: четвёртая и последующие проверки, две подсказки либо готовое решение.

Редактирование, очистка, отмена и справка по интерфейсу бесплатны. Содержательные подсказки раскрываются в три шага. Звёзды остаются игровой оценкой конкретного прохождения, а доступ к следующим главам определяется отдельным освоением необходимых навыков.

Адаптация проходит лестницу `blocks → blocks_with_code → guided_code → code_tokens → free_code`, максимум на одну ступень за решение. Для ускорения нужны mastery ≥ 0.72 и минимум два новых самостоятельных успеха по целевым навыкам после предыдущей смены формата. Пошаговое знакомство не считается самостоятельным успехом. При среднем mastery сохраняется обычный курс.

Две разные непустые ошибки в текущем задании предлагают короткую corrective-практику и, если вариант доступен, возвращают одну ступень помощи. Пустая проверка, повтор того же ответа и изменение только пробелов в уже разобранном коде не создают новое evidence. У повторений отдельные сессии/черновики; они не закрывают основной урок и не начисляют ему звёзды. После практики ученик возвращается в то же задание, а не в начало главы. Review учитывает реальный перерыв от трёх дней и доступные prerequisites.

## Сохранение и аналитика

AI Tutor для основного адаптивного курса добавляет три последовательные подсказки, объяснение ошибки, понятия и похожий пример. Он получает тип ошибки от существующей проверки и краткую структуру решения без текста, имён переменных и личных данных. Ответ проходит отдельную проверку; при сбое сразу остаётся обычная подсказка. AI не оценивает ответ, не меняет освоение навыков и не открывает главы. Курс из 100 заданий сохраняет собственную систему подсказок.

Основной провайдер — Groq. Для включения на Vercel задайте серверный `GROQ_API_KEY` и `AI_TUTOR_ENABLED=true`, по желанию `AI_EXPLANATIONS_ENABLED=true` и `AI_EXAMPLES_ENABLED=true`. По умолчанию используется `openai/gpt-oss-20b`; модель можно изменить через `GROQ_TUTOR_MODEL`. Если Groq не настроен, остаётся возможность использовать `OPENAI_API_KEY` и `OPENAI_TUTOR_MODEL`. Для клиентской сборки задайте `VITE_AI_TUTOR_ENABLED=true`, `VITE_AI_EXPLANATIONS_ENABLED=true`, `VITE_AI_EXAMPLES_ENABLED=true`. Затем разверните проект заново. Ключ должен находиться только в серверных переменных; без него AI Tutor выключен, а уроки продолжают работать. Генерация новых заданий остаётся отключённой. Лимит клиента — восемь запросов на урок, лимит API — 30 запросов за минуту на адрес в пределах одного экземпляра функции. Бесплатный тариф Groq имеет лимиты запросов и токенов.

Проверки AI без реального ключа входят в `npm run test:smoke`; сценарий в браузере с тестовым провайдером запускается при `VITE_AI_TUTOR_ENABLED=true`, `KODIK_AI_UI_TEST=true` и `npm run test:ui -- tests/aiTutor.spec.ts`.

Локально сохраняются завершение, лучшие звёзды, попытки, уровень подсказки, skill state, текущая глава/урок, шаг знакомства, Blockly workspace, текст редактора, выбранные tokens, формат поддержки и последний результат проверки. Формат версии 4 использует прежний ключ `kodik-progress-v1`; старые завершения, звёзды и совместимые черновики сохраняются. Прогресс без mastery получает консервативно восстановленное освоение из уже завершённых заданий. При отказе записи обучение продолжается в памяти вкладки с предупреждением.

Для повторного user testing собираются последние 500 локальных событий: открытие задания, первое действие, добавление блока, шаг знакомства, проверка, подсказка, раскрытие Python, повтор, `adaptive_decision`, `support_changed`, `corrective_inserted`, `corrective_completed`. Введённый текст в события не записывается. Учебный ответ сохраняется отдельно как локальный черновик, не как аналитика. Внизу карты курса есть выгрузка JSON. Никакой внешней аналитики нет.

## Архитектура

- `src/course.ts`, `courseBase.ts`: главы и задания, совместимые ID старого курса.
- `src/course100.json`, `course100Solutions.ts`: карточки и эталоны нового курса.
- `src/course100Runtime.ts`, `Course100.tsx`: безопасный запуск, проверка и интерфейс 100 заданий.
- `src/tutorial.ts`: повторно используемые описания шагов и условия их завершения.
- `src/BlocklyEditor.tsx`: Blockly, соединение блоков, редактирование, фокус и черновики.
- `src/learningEngine.ts`: Blockly → IR → Python, ограниченный интерпретатор и проверка результата/структуры.
- `src/textLearning.ts`: безопасное преобразование учебного текстового ответа в тот же IR.
- `src/skills.ts`, `mastery.ts`: каталог навыков, support levels и заменяемая формула освоения.
- `src/validation.ts`: небольшая расширяемая taxonomy структурированных ошибок.
- `src/adaptiveSupport.ts`: единые пороги и решение о ступени поддержки.
- `src/learningFlow.ts`, `supportVariants.ts`: применение решения, сохранение формата, проверяемые варианты ввода и безопасный fallback.
- `src/exerciseSelector.ts`, `practicePool.ts`: выбор основной/corrective/review практики с учётом prerequisites и отдельными ID повторений.
- `src/achievement.ts`: звёзды, сессии и доступность глав по mastery prerequisites.
- `src/LearningLesson.tsx`, `LearningUI.tsx`, `App.tsx`: занятие, диалоги, главная и карта.
- `src/progress.ts`, `analytics.ts`: сохранение, необязательный Supabase, локальные события.

Произвольный Python не исполняется. Безопасный parser поддерживает учебное подмножество: присваивание, `print`, арифметику, сравнения, `if/else`, `for ... in range(...)`, функции без параметров и вызовы. Всё преобразуется в тот же IR, что и Blockly. Нет `eval`, импортов и доступа учебной программы к сети/файлам/ОС. Действуют лимиты выполнения: 1000 шагов, 40 вложенных вызовов, 200 блоков, строки до 2000 символов, абсолютные значения чисел до 10¹².

Blockly загружается отдельно при открытии занятия. Внешних шрифтов и ресурсов учебного интерфейса нет. Загруженное занятие работает при потере сети; загрузка с нуля без сети и service worker не реализованы.

## Supabase (необязательно)

1. Применить `supabase/migrations/001_progress.sql`, затем `002_learning_state.sql`.
2. Включить Anonymous Sign-ins.
3. Создать `.env.local` по `.env.example`: URL и публичный anon key (не service-role).
4. Пересобрать приложение.

Существующая RLS сохранена. В облако передаются завершения и учебное состояние, черновики Blockly остаются локально. Сетевой сбой не блокирует локальное обучение. Входа в аккаунт с другого устройства пока нет. В поставляемой версии ключей нет, реальный Supabase не проверялся.


Playwright сам поднимает Vite-сервер и использует установленный Edge с изолированными тестовыми данными. Для проверки уже запущенного стенда можно передать `KODIK_TEST_URL`.
