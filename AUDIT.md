## Существующая архитектура

- React 19, TypeScript, Vite 7; serverless API AI и событий, Capacitor для Android.
- BlocklyEditor и learningEngine преобразуют блоки в независимое представление программы. Сохранить курс и постепенный переход к тексту.
- MinimalCodeEditor: подсветка, номера строк, отступы. Повторно использовать.
- pythonRuntime/pythonExecution — собственный интерпретатор учебного подмножества Python: print/input, числа, строки, списки, условия, циклы и функции. Ограничены операции, списки и вывод. Это НЕ CPython: нет импортов, классов и библиотек.
- Задания — TypeScript-объекты с validate-функциями. Преподаватель не может создавать их без изменения кода. Решения попадают в клиентский набор: он не подходит для скрытых B2B-тестов.
- progress хранит локальные данные; cloudProgress синхронизирует часть метаданных через Supabase. Модели школ, групп и назначений нет.
- AI tutor управляется флагами. По запросу владельца отключается безусловно, исходники сохраняются.

## Решение

Сохранить старый курс по `?legacy=1`, Blockly, движки и редактор. Новый контент, попытки и черновики хранить на сервере. Добавить desktop B2B и SQLite. Одного экземпляра достаточно для пилота; для горизонтального роста нужны PostgreSQL и отдельный runner.

Новый код проверяется в отдельном процессе с ограничениями памяти, времени, операций и вывода. Текст разбирается учебным парсером, а не выполняется как JavaScript или системный Python. Файловые/сетевые примитивы отсутствуют в языке. Node permissions — дополнительная мера, а не песочница для произвольного JavaScript.

## Границы

Полный Python требует контейнерного runner. Legacy сохраняет прежний локальный прогресс, не являясь B2B-заданием. Для коммерческого использования нужны HTTPS, резервные копии, политика хранения данных детей, мониторинг и нагрузочное тестирование.
