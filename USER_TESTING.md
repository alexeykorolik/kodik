# Повторный тест с новичком

Цель: проверить, сможет ли человек без программирования пройти первые пять упражнений без устных инструкций, объяснить связь блоков с Python и самостоятельно изменить программу.

## Подготовка

Использовать новый профиль браузера на http://127.0.0.1:4173/, чтобы начать без прогресса. Не очищать основной профиль участника. Провести отдельные сессии на телефоне и компьютере. Записать размер экрана и устройство. Объяснить: «Мы проверяем приложение. Если что-то непонятно, это полезно узнать».

## Сценарий без подсказок наблюдателя

1. Попросить начать обучение и пройти первые пять заданий. Не объяснять Blockly, print или расположение кнопок.
2. Отмечать паузы, неверные нажатия, попытки перетаскивания, потерю поля ввода, просьбы о помощи и понимание обратной связи. При вопросе сначала спросить: «Что ты ожидал здесь сделать?».
3. После первого знакомства спросить: «Что делает эта команда? Что находится в кавычках? Какой блок соответствует этой части строки?». Не подсказывать правильный ответ.
4. На самостоятельном задании попросить изменить сообщение, затем объяснить, почему изменился Python.
5. После первой главы спросить: «Что означают звёзды? Что нужно, чтобы открыть следующую главу? Как улучшить результат?».
6. Закрыть и снова открыть страницу; попросить продолжить. После ещё одного задания по коду спросить, как бы участник написал похожую команду сам.

## Данные и критерии

С карты курса выгрузить JSON событий. Зафиксировать время до первого действия/блока, число проверок/подсказок, шаги с остановками и повторные прохождения. Событие python_view означает раскрытие кода; само наличие зеркала на странице не доказывает, что человек его прочитал.

Для каждого участника отметить: первые пять завершены без устной помощи; понятна разница команды и значения; самостоятельно изменено сообщение; объяснена связь с Python; верно выбрана строка кода; понятны звёзды и открытие глав. Записать дословные затруднения и контекст, а не только общий отзыв.

Любая потребовавшаяся устная инструкция — найденная проблема: уточнить конкретный текст/шаг/экран и повторить тест после исправления. Результаты настоящих участников в этот файл пока не внесены: автоматизированный тест не подменяет user testing.
