# Демонстрация адаптации — 60–90 секунд

Это обычное приложение, не специальный demo mode. Ни пороги, ни проверки не меняются. Подготовка автоматически проходит настоящее знакомство и самостоятельные решения через интерфейс. Счётчики и mastery нельзя вручную подставлять для этой демонстрации.

## Подготовка

Из корня проекта выполнить `npm run demo:open`. Скрипт собирает production-версию, поднимает отдельный preview на `127.0.0.1:5190`, решает задания в отдельном браузере и открывает чистое демонстрационное окно Edge. Основной профиль пользователя не затрагивается. Если порт занят, скрипт остановится; чужой сервер не завершается.

Для подготовки без видимого окна: `npm run demo:prepare`. В `artifacts/` сохраняются настоящие снимки прогресса и экрана: `demo-first-blocks`, `demo-blocks-with-code`, `demo-guided-ready`, `demo-tokens-ready`, `demo-free-ready`. Они не включаются в Git. Закрытие демонстрационного окна останавливает его локальный preview.

На подготовленном экране открыто «Теперь — твоё сообщение» в формате с пропуском. История до него: первое знакомство блоками и три самостоятельных решения блоками с Python. Новые решения в показе проверяет тот же движок.

## Основной показ

1. 0–10 секунд: показать снимки первого знакомства и блоков с Python, затем живой открытый пропуск. Объяснить: «Уже есть подтверждённые решения; следующая ступень убрала блоки, но оставила готовую часть программы». Не выдавать снимки за живое действие.
2. 10–30 секунд: выбрать `"Мне нравится Python"`, проверить. Через «К карте курса» снова открыть «Теперь — твоё сообщение». Повторить правильный ответ и снова открыть урок. После двух **новых** самостоятельных успехов появляются части кода и объяснение перехода.
3. 30–55 секунд: собрать `print`, `(`, `"Мне нравится Python"`, `)` и проверить. Повторно открыть, решить второй раз, снова открыть. Появится обычное текстовое поле.
4. 55–75 секунд: самостоятельно ввести `print("Мне нравится Python")`, проверить и раскрыть результат. Видны реальный вывод и сохранённые звёзды.

Не обещать переход после одного ответа: устойчивость требует два новых подтверждения между сменами формата. Реальное время зависит от темпа человека; провести репетицию заранее.

## Альтернативный показ восстановления — около минуты

В том же открытом guided-уроке выбрать `"Другое сообщение"` и проверить. Затем выбрать `Мне нравится Python` без кавычек и нажать «Проверить снова». Кнопка сразу проверяет текущий ответ, отдельного закрытия ошибки больше нет. Это две разные непустые ошибки, а не повтор одной кнопки. Нажать «Закрепить на примере».

В короткой практике с блоками собрать правильное сообщение, проверить и продолжить. Приложение возвращает **в тот же урок**, сохраняет основной прогресс и добавляет помощь. Повторение не закрывает основной урок и не начисляет ему звёзды. Завершить исходный урок самостоятельно.

Не пытаться показать всю успешную лестницу и восстановление за одни 60 секунд: выбрать одну историю, вторую оставить для вопроса комиссии.
